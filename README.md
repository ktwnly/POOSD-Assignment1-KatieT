# POOSD-Assignment1
Public GitHub repo for COP4331 Assignment 1

<strong>The COLORS Application</strong> allows users to log in with a username and password, which then takes them to a new screen. On this new screen, users can add colors on the bottom of the page, and once saved, they can search for these colors using the search bar, and the results matching the search will be displayed below the search bar. The users' data is stored, so even if they log out and log back in, the colors they added stay saved and accessible.

<strong>Technologies Used:</strong> The LAMP stack was used to complete this project. Linux was the Operating System used, the Apache HTTP Web Server was the system receiving network requests from the user's browser, MySQL was used as the database and storage for this project, and stored user credentials, saved colors, and application data. Finally, PHP was used to implement the backend API endpoints, receiving requests from the JavaScript frontend and communicating with the MySQL database to send or store information from the web app.

<strong>Setup Instructions:</strong> First, you must obtain a Linux-based server with the LAMP stack installed. This project was built using a DigitalOcean Droplet running Ubuntu with Apache, MySQL, and PHP. Then, clone this repository onto the server. Place the frontend files (index.html, color.html, css/, js/, and images/) in the server's web root, /var/www/html. Next, place the PHP API files (Login.php, AddColor.php, and SearchColors.php) in /var/www/html/LAMPAPI. Create your MySQL database and configure the required tables and data. Then configure the PHP database connection with the credentials for the MySQL user on the server. Database passwords and other credentials should not be committed to this repository. Lastly, configure a domain name to point to the server's IP address.

<strong>Run and Access the Application:</strong> After the server, database, and PHP API have been configured, the app can be accessed through the domain name connected to the server. When you open the domain in a web browser, the application should display the login page (index.html). From there, test the app's functionality by: logging in with valid credentials from the MySQL database, adding/searching for a color, and logging out to then log back in and verify the saved colors are still connected to the user. The frontend communicates with the backend through the PHP API endpoints: Login.php, AddColor.php, and SearchColors.php.

<strong>Assumptions and Limitations:</strong> A Linux-based server running Apache, PHP, and MySQL is required. You must also have access to a private server droplet or something similar, and you must be able to purchase a custom domain name to host this project. Limitations of this project currently include: there's no way to create a new user from the webpage itself, you'll need to go into the MySQL database and manually input a new user, also, there's no way to keep track of an entire list of the colors that have been added already, because of this, it will be hard for users to keep track of what colors they've added and what colors they haven't added yet. There has been no AI usage in the creation of this project.
